# Novem-ever Yours

A private-feeling, mobile-first anniversary microsite built with plain HTML, CSS and JavaScript-free interactions.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Add your photographs

Create `assets/photos/` and add your own images using these exact filenames:

- `cover.jpg` — hero photograph
- `memory-01.jpg` — main gallery photograph
- `memory-02.jpg` — gallery photograph
- `memory-03.jpg` — gallery photograph

The page currently shows a helpful fallback where a photo is missing. Use photographs you have permission to publish.

## Publish with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for the Pages deployment to finish.

## Privacy

This repository is currently public. Do not commit personal photographs, videos, chat exports, or other private material unless you intentionally want them publicly accessible. For a personal anniversary site, changing the repository to **Private** before uploading media is recommended. GitHub Pages availability for private repositories depends on the account/plan.

## Design direction

Editorial winter romance: warm ivory, muted winter blue, deep burgundy, serif-led typography, generous whitespace, restrained motion and photography-first layouts.
