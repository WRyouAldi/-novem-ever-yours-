# Optional video assets

No video is currently embedded in the microsite. If a video feature is approved later:
- Use an MP4 encoded with H.264/AAC for broad browser compatibility.
- Prefer 720p or 1080p and compress for mobile delivery.
- Keep the clip short and provide a poster thumbnail.
- Add captions or a text alternative when the video contains meaningful speech.
- Do not autoplay audio; provide clear playback controls.
- Be aware that any media delivered by a public website can be copied by visitors.

Do not add video files until the hosting/privacy decision is settled.
