# Photo assets

Place only photographs you have both permission and intention to publish in this folder.

## Required slots
| Filename | Used for | Suggested crop |
|---|---|---|
| cover.jpg | Hero portrait/photo | Portrait 4:5 or 3:4 |
| memory-01.jpg | Main gallery image | Portrait or landscape |
| memory-02.jpg | Gallery image | Landscape |
| memory-03.jpg | Gallery image | Landscape |

Keep these filenames unchanged unless the corresponding paths in index.html are updated too.

## Preparation
- Keep original photographs backed up outside the repository.
- Export web copies as JPEG or WebP; if using WebP, update the matching HTML path.
- Aim for roughly 150–350 KB per photograph where quality allows.
- Resize large originals before committing; around 1600–2000 px on the long edge is generally sufficient.
- Remove location metadata (EXIF/GPS) from exported copies if you do not want it shared.
- Use descriptive alt text in index.html rather than generic labels once the actual photos are selected.

No personal photos are included yet. Empty folder is intentional.
